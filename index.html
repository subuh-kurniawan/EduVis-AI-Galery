Fondasi Kedaulatan AI Korporat

Arsitektur tangguh berfokus pada privasi, efisiensi komputasi, dan kepatuhan data ketat.

Kedaulatan Data Mutlak

Data sensitif organisasi Anda tidak pernah dikirimkan ke server publik atau model pihak ketiga. Seluruh inferensi dan retensi sesi berlangsung terisolasi pada perangkat lokal.

Akselerasi Hardware Nyata

Optimalisasi komputasi tensor memanfaatkan akselerator GPU lokal melalui WebGPU dan XNNPACK untuk menghasilkan token per detik yang stabil tanpa biaya langganan API berulang.

Multi-Tier OPFS Storage

Model berbobot gigabyte disimpan rapi di Origin Private File System browser. Inisialisasi sesi kedua dan seterusnya instan tanpa unduhan berulang.

Distribusi LAN Korporat

Host pada workstation internal kantor dan bagikan akses ke seluruh laptop tim di jaringan lokal dengan sertifikat TLS terpercaya tanpa konfigurasi internet luar.

Protokol Keamanan Akses Jaringan Lokal (LAN)

Pastikan perangkat klien Anda berada dalam satu subnet jaringan lokal dengan workstation host. Bila browser menampilkan peringatan sertifikat keamanan, unduh Sertifikat CA Lokal, percayai sertifikat pada perangkat Anda, lalu akses kembali portal ini. Jangan membagikan tautan ini ke jaringan publik tanpa lapisan VPN korporat.

Petunjuk penggunaan & pemuatan model

Pilih workspace untuk mulai menggunakan asisten. Jika model belum tersedia, impor model LiteRT-LM terlebih dahulu dari pengaturan.

  1. 1

    Pilih workspace

    Buka salah satu workspace di portal. Untuk mengelola model lokal, mulai dari Utama.

  2. 2

    Siapkan file model

    Letakkan file model berformat .litertlm di folder proyek aplikasi pada komputer host sebelum mengimpornya.

  3. 3

    Impor ke LiteRT-LM

    Di workspace Utama, buka Atur pada sidebar, pilih file di bagian Impor Model Lokal, lalu tekan Impor ke LiteRT-LM.

  4. 4

    Pilih dan gunakan model

    Pilih model yang sudah diimpor pada pengaturan model. Setelah status model siap, kembali ke percakapan dan mulai chat.
